Tu vas créer la structure de conception pour une nouvelle feature.

1. Lire les specs de format : `.project/docs/formats.md`

2. Créer le dossier `.project/features/<feature>/` avec :
   - `manifest.json` (métadonnées de la feature)
   - `wireframes/` (dossier vide)

3. Mettre à jour les documents consolidés si nécessaire :
   - Ajouter section dans `user-stories.md`
   - Ajouter annotation `%% @feature: <name>` dans `sitemap.mmd`
   - Ajouter annotation `%% @feature: <name>` dans `database.mmd`

4. Confirmer la création
